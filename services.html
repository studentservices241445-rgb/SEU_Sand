الخدمات

هنا نرتّب الخدمات بشكل واضح: محتوى مجاني + خدمات مدفوعة (دعم دراسي/شرح/متابعة).
مهم: لا نقدم تنفيذ واجبات/اختبارات بدل الطالب — نحن نقدم تنظيم، شرح، مراجعة، وتوجيه.

إنشاء فاتورة (مدفوع) محتوى مجاني تواصل/بلاغ

محتوى مجاني

للطلاب الذين يريدون مصادر وأدوات تساعدهم على النجاح بدون تكلفة.

  • دليل روابط مهمة (Blackboard / Banner / البريد الجامعي)
  • قوالب تنظيم مذاكرة + جدول أسبوعي
  • نصائح للسنة الأولى المشتركة واختبار STEP
  • الأسئلة الشائعة
فتح الأدلة

خدمات مدفوعة (بشكل نظامي)

لمن يحتاج متابعة مكثفة خلال الترم أو جلسات شرح ومراجعة.

  • اشتراك ترم كامل: متابعة + شرح + تذكيرات + تنظيم خطة أسبوعية
  • خدمات فردية: جلسة شرح/مراجعة، تدقيق لغوي، دعم تقني…
  • خصم 10% عند الدفع الكامل للترم
ابدأ (فاتورة ورسالة جاهزة)

1) اشتراك متابعة ترم كامل

مناسب لمن يريد تنظيم أسبوعي + مراجعة إنجاز + تذكيرات للمواعيد.

خطة أسبوعية جلسات شرح ملخص إنجاز
يشمل تجهيز جدول متابعة قابل للحفظ PDF قبل التأكيد النهائي.

2) خدمات فردية

اختيار خدمات حسب احتياجك بدون اشتراك كامل.

جلسة شرح مراجعة مشروع تدقيق لغوي دعم تقني
يمكنك اختيار أكثر من خدمة داخل نموذج الفاتورة.

3) اختبار STEP

تحضير منظم + خارطة طريق + جلسات (حسب الطلب).

صفحة STEP موقع الدورة

ماذا يحصل بعد "إنشاء فاتورة"؟

  1. تعبئة نموذج الخدمة + اختيار المواد وخطة الدفع.
  2. عرض الفاتورة بالتفاصيل + زر نسخ التفاصيل.
  3. زر "إنشاء جدول متابعة" (نموذج توضيحي) وتحميله PDF.
  4. زر فتح واتساب/تليجرام برسالة جاهزة فيها بيانات التحويل.
⚠️ تنبيه النزاهة: المنصّة تقدم شرح/متابعة/تجهيز فقط، ولا تنفذ واجبات/اختبارات بدل الطالب.
