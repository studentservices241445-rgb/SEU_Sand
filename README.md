# خدمات طلاب SEU — موقع ثابت + PWA على GitHub Pages

هذا المشروع عبارة عن **موقع ثابت** (Static) جاهز للنشر على **GitHub Pages**،
ومُجهّز ليعمل كتطبيق **Progressive Web App (PWA)** يمكن تثبيته على الجوال/الكمبيوتر.

## أهم الميزات

- ✅ قابل للتثبيت كتطبيق (Manifest + Service Worker).
- ✅ يعمل دون اتصال بعد أول زيارة (Offline cache).
- ✅ زر مشاركة في كل صفحة (Web Share API + نسخ تلقائي عند عدم الدعم).
- ✅ نموذج خدمات مدفوعة:
  - إنشاء فاتورة تلقائية
  - خصم 10% عند الدفع الكامل للترم
  - توليد رسالة جاهزة للواتساب/التليجرام
- ✅ توليد **جدول متابعة أسبوعي** كنموذج توضيحي (ملون) + حفظه PDF عبر الطباعة.
- ✅ تنزيل تذكير أسبوعي للتقويم (.ics) بدل الإشعارات (لأن المشروع ثابت بدون خادم).
- ✅ نموذج دعم يولّد رسالة بلاغ مفصلة + يفتح بوت التليجرام/واتساب.

> **مهم (نزاهة أكاديمية):** المشروع مصمم للدعم الدراسي (شرح/متابعة/تنظيم/مراجعة) فقط.

---

## هيكل الملفات

- `index.html` الرئيسية
- `services.html` الخدمات
- `order.html` نموذج الطلب + الفاتورة
- `dashboard.html` جدول المتابعة + PDF + .ics
- `support.html` نموذج البلاغ
- صفحات إضافية: `guides.html`, `step.html`, `faq.html`, `about.html`, `privacy.html`, `terms.html`
- `manifest.webmanifest` إعدادات PWA
- `sw.js` Service Worker
- `assets/` ملفات CSS/JS والأيقونات

---

## نشره على GitHub Pages

1) أنشئ Repository جديد على GitHub  
2) ارفع كل الملفات إلى الفرع `main` في الجذر (root)  
3) اذهب إلى: **Settings → Pages**  
4) اختر:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5) افتح رابط الموقع بعد النشر.

## تخصيص سريع

### 1) تغيير الأسماء والأيقونات
- عدّل: `manifest.webmanifest`
- عدّل: العنوان في `index.html` وباقي الصفحات
- بدّل الأيقونات:
  - `assets/icons/icon-192.png`
  - `assets/icons/icon-512.png`

### 2) تعديل الأسعار
في الملف: `assets/js/app.js`  
ابحث عن كائن `PRICING` وعدّل:
- سعر المادة للترم
- أسعار الخدمات الفردية
- نسبة خصم الدفع الكامل

### 3) تعديل أرقام التواصل والبوت
في `assets/js/app.js` ابحث عن:
- رقم الواتساب: `966533940866`
- معرف تليجرام: `Student_services25`
- بوت التليجرام: `SEU_Services_SandBot`

### 4) تعديل نصوص المشاركة (آيات/أحاديث/نصائح)
في كل صفحة HTML ستجد:
```html
<meta name="share:text" content="...">
```
عدّل النص بما يناسبك.

## ملاحظة تقنية عن الإشعارات الأسبوعية

لأن الموقع **Static** بدون خادم:
- لا توجد إشعارات Push مضمونة تعمل والتطبيق مغلق.
- لذلك استخدمنا ملف `.ics` الذي يمكن إضافته لتقويم Google/Apple/Outlook لتفعيل تذكير أسبوعي.

إذا رغبت مستقبلًا بميزة إشعارات Push حقيقية:
ستحتاج Backend (مثل Firebase Cloud Messaging أو خادم صغير) لتوليد Push Subscriptions.
